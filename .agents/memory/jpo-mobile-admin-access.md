---
name: Discreet mobile admin access
description: User requirement against publicly visible admin entry points on phones.
---
Do not add a visible Admin button or publicly labeled admin entry to the office.

**Why:** The user rejected the mobile Admin button because everyone would see that an admin button exists.

**How to apply:** Use a discreet entry mechanism for mobile access, keeping the existing password authentication and server-side admin/owner restrictions. Do not describe a hidden gesture as a substitute for authorization.
