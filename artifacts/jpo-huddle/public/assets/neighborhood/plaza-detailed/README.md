# Detailed plaza storefronts

Original AI-generated storefront atlas: `attached_assets/generated_images/plaza-storefront-atlas.png`.
Generated for this project from the user's requested dark-outlined, richly textured pixel-art direction.

Each transparent building was cropped independently, reduced to an 80-pixel-wide native grid,
and palette-limited. Phaser enlarges the sprites without stretching their aspect ratio.
These are individual facade sprites, not flattened maps. Walking surfaces, doors, collisions,
and destination IDs remain authored separately in the shared plaza geometry.

Atlas order: cafe, furniture-shop, garden-shop, decor-shop, diner, bakery, sushi, museum.
