Phase 2 — Add furniture to every room using the 
Interiors_free_16x16.png tileset.

The tileset is at /public/assets/Interiors_free_16x16.png
Size: 256x1424px, 16 cols x 89 rows, each tile 16x16px.
Render all furniture at 3x scale (48x48 per tile).
ctx.imageSmoothingEnabled = false on the canvas.

Load the tileset image in Phaser preload():
this.load.image('interiors', '/assets/Interiors_free_16x16.png')

Then in create() draw furniture using Phaser Image objects 
with setOrigin(0,0) and setScale(3).
